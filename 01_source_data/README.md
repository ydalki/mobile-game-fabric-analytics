# Source Data

This folder contains sample files and documentation for the synthetic mobile game analytics dataset used in this project.

The full raw dataset is not included in the repository due to its size.

The source data represents a free-to-play mobile puzzle game and includes:

- Player profiles
- Game sessions
- Level events
- Purchases
- Ad events
- Marketing spend

The complete dataset was processed in Microsoft Fabric using a Bronze–Silver–Gold Medallion Architecture.
